# Cybersecurity Risk Assessment

## Project Context

NorthStar Professional Services is a fictional organization with approximately 75 employees. The organization handles client information and relies on information technology to support its daily operations.
As the organization has grown, its technology environment and security practices have developed over time. This project presents a cybersecurity risk assessment of that environment to identify and evaluate risks that could affect the organization.
The assessment is focused on risk identification and analysis. It is not a penetration test and does not involve active exploitation of systems.
